# Avaneesh M Dethan, Digital Portfolio

The personal portfolio of Avaneesh M Dethan, a BBA student at T A Pai Management Institute, Bengaluru. It tells the story in eight chapters: introduction, about, leadership, academic projects, things I've built, life beyond work, what's next, and how to get in touch.

## Run it locally

```bash
npm install
npm run dev
```

Then open http://localhost:3010.

## Build

```bash
npm run build
```

The finished site is written to `out/` as plain static files, ready for Vercel or Netlify.

## Editing

All the words on the site live in the `content` folder. `HANDOFF.md` explains how to change text, add photos and make a PDF version of the portfolio.

Built with Next.js, TypeScript and Tailwind CSS.
